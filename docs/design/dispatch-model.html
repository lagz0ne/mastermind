4 Environment: central definition, local binding

In Mastermind new: mm-210.30

What the environment is. Edited on a new page, /environments. A bead points to it with one label.

type Environment = {
  name: string;       // "mastermind"
  repo: string;       // git URL
  ref: string;        // default branch
  requires: string[]; // ["bun>=1.4", "docker"]
  setup: string[];    // prepare a checkout
  check: string[];    // prove readiness
  secrets: string[];  // names only
  agent?: { provider?: string; mode?: string };
  instructions?: string; // added to each prompt
};

On the user machine new: mm-210.31

Where the environment is on that machine, and what Mastermind can do there. The user owns this file.

"environments": {
  "mastermind": {
    "dir": "~/dev/mastermind",
    "allowSetup": true
  }
}
  • Setup runs one time for each checkout and each setup version, and only if the binding allows it.
  • Check runs before each start. A failed check gives the bead back, with the output.
  • An environment with no binding is declined with a clear reason.

5 Adapter routing: the user controls the Paseo

{
  "targets": {
    "laptop":  { "provider": "claude/claude-opus-5-5",
                 "mode": "bypassPermissions" },
    "gpu-box": { "paseoHost": "ssh://gpu",
                 "provider": "codex" }
  },
  "rules": [  // first match wins
    { "match": { "env": "mastermind", "stage": "work" },
      "target": "laptop" },
    { "match": { "labels": ["req:gpu"] },
      "target": "gpu-box" },
    { "match": {},
      "decline": "no rule for this work" }
  ]
}

Order of authority

  1. Hard requirements of the instruction. Tools, environment, secrets. The adapter meets them or declines the work.
  2. The user's rule. It selects the target: Paseo host, provider, mode.
  3. Preferences of the instruction. They apply only where the user's rule leaves a field open.
  4. No rule matches. The adapter declines and gives the reason.

The first report of each dispatch names the target. The bead timeline shows where the work runs.

7 Your decisions

A. Central definition, local binding

Mastermind holds what an environment is. The adapter of each user holds where it is on their machine, and if setup commands can run there. Reply "A ok", or say what must change.

B. No silent fall back for a direct offer

If the addressed runner declines or is offline, the bead waits and shows the reasons. It goes to a queue only if the rule has fallback. Reply "B ok", or say what must change.

C. Login

Open /login on the production site. Send the code and the account name you want in the chat.
